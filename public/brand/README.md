# Activos de marca

## Archivos disponibles

| Archivo | Tipo | Descripción |
|---|---|---|
| `taju-isotipo.svg` | Isotipo | Solo el símbolo (gato), sin wordmark |
| `taju-isotipo-monocromático.svg` | Isotipo | Variante monocromática del símbolo |
| `taju-imagotipo.svg` | Imagotipo | Símbolo + wordmark |
| `taju-imagotipo-v2.svg` | Imagotipo | Variante vertical, con isotipo arriba y logotipo completo abajo |
| `taju-logotipo-completo.svg` | Logotipo | Logotipo completo |
| `taju-logotipo-only-taju.svg` | Logotipo | Solo el texto "taju" (wordmark) |

## Contenido fuente (`raw_content/`)

Archivos de referencia y fuente original; no usar directamente en la interfaz.

| Archivo | Descripción |
|---|---|
| `taju-logotipo.svg` | SVG de origen del logotipo |
| `TAJÚ LOGO.ai.png` | Previsualización del archivo `.ai` |
| `TAJU LETRAS.png` | Letras aisladas |
| `logo taju.jpg.jpeg` | Imagen raster de referencia |

## Reglas de uso

- Por debajo de 120 px de ancho usar `taju-isotipo.svg`, nunca el imagotipo completo.
- Para fondos oscuros o estampado usar `taju-isotipo-monocromático.svg`.
