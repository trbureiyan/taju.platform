| Archivo esperado | Descripción | Usar cuando |
|---|---|---|
| `taju-vertical.svg` | Logotipo vertical (isotipo + wordmark apilados) | Uso general |
| `taju-horizontal.svg` | Logotipo horizontal (isotipo + wordmark en línea) | Header, navbar |
| `taju-contorno.svg` | Versión en contorno / monocromo | Fondos oscuros, estampado |
| `taju-isotipo.svg` | Solo el gato, sin wordmark | < 120px de ancho, favicon base |

Regla: por debajo de 120px de ancho usar `taju-isotipo.svg`, nunca `taju-horizontal.svg`.
